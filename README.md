# tg-notes-bot

Telegram-бот для заметок и напоминаний на C++17. Заметки хранятся в SQLite, запросы к Telegram Bot API выполняются через libcurl. Взаимодействовать с ботом можно командами и кнопками.

## Как устроен проект

- `src/main.cpp` — запуск, обработка команд, диалоги с пользователем и отдельный поток проверки напоминаний раз в 5 секунд.
- `src/telegram_client.cpp` — получение обновлений через long polling, отправка сообщений и обработка нажатий на кнопки.
- `src/notes_store.cpp` — сохранение, выборка и удаление заметок в SQLite. Доступ к базе защищён мьютексом; заметки разделяются по чатам.
- `include/` — заголовки клиента Telegram и хранилища.
- `third_party/nlohmann/json.hpp` — библиотека для работы с JSON.
- `CMakeLists.txt` — настройки сборки и подключения зависимостей.

Основной поток получает и обрабатывает сообщения, а поток напоминаний ищет записи с наступившим сроком. После успешной отправки напоминание отмечается выполненным. Незаконченные диалоги хранятся в памяти, заметки — в файле `notes.db`.

## Сборка и запуск

Нужны компилятор C++17, CMake 3.16+, libcurl и SQLite3. Для Ubuntu/Debian:

```sh
sudo apt install build-essential cmake libcurl4-openssl-dev libsqlite3-dev
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
cp .env.example .env
```

Получите токен у [BotFather](https://t.me/BotFather) и вставьте его в `.env`:

```dotenv
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
```

Запускайте из корня проекта, чтобы бот нашёл `.env`:

```sh
./build/tg_notes_bot
```

Токен также можно передать через переменную окружения `BOT_TOKEN`; она имеет приоритет над файлом. База `notes.db` создаётся в текущей рабочей папке. Для остановки нажмите `Ctrl+C`; завершение может занять время до окончания текущего сетевого запроса.

## Команды

| Команда | Действие |
| --- | --- |
| `/start`, `/help` | Открыть меню и справку |
| `/new` | Создать заметку в диалоге |
| `/add текст` | Ввести заметку, затем выбрать, нужно ли напоминание |
| `/remind 30 текст` | Создать заметку с напоминанием через 30 минут |
| `/remind 2ч30м текст` | Напомнить через 2 часа 30 минут |
| `/remind 12:35 текст` | Напомнить в указанное время |
| `/list` | Показать последние 50 заметок чата |
| `/del 3` | Удалить заметку с ID 3 из текущего чата |

Время суток определяется по часовому поясу компьютера, на котором запущен бот. Если указанное время уже прошло, напоминание переносится на следующий день. Максимальный интервал — 30 суток. Для отправки напоминаний бот должен быть запущен.

## Локальные данные

`.env`, папка сборки `build/` и `notes.db` уже указаны в `.gitignore`. В репозитории остаётся только `.env.example` без настоящего токена. Не добавляйте токен в исходники и не используйте `git add -f` для файлов с секретами.
